## 发布前与上线后

发布必须重新 fetch 双仓库 main 并核对当前 Worker、Pages 部署和公开 release marker。若源代码或生产部署变化，停止发布、整合并重验受影响范围。前后端 main 只允许快进更新。

按私有备份 → 0041 迁移 → 对应后端 Worker → 支持配置 CAS 发布 → 前端 main / Cloudflare Git integration 发布。前端使用 `scripts/release-build.mjs`，不使用原始 Pages 上传。

2026-10-14 用户明确将真实输入法、手机触控、现有 Passkey、原生日历客户端验收移至上线后。本次不重建或改变设备凭据。正式发布后仍须完成这些硬件检查。

正式生产账号、图库、企划、编辑入口、收款码和发布标记的检查，以及实际提交和部署 ID，追加到此次工作区发布记录。保留“本地、生产基线、发布后生产”三种证据的区别；不得将原生产基线检查算作新版已发布的证据。

## 云端检出修复

首次云端构建因地点联动测试固定引用本机后端目录失败，前端未发布。修正测试目录检测后，本机明确检测隔离后端并执行全部 830 项；仅有前端的云端检出执行 796 项前端测试，34 项联动测试已在本机匹配源码执行。公告使用实际前端发布日 2026-10-15。

## 正式预览目录补验

生产花譜预览发现缺失角色与分类元数据导致 BEMA 引用不能解析。已补充 roles、classification、lifecycle、articleCategory，逐项比较 5,508 份预览元数据的路径与完整公开元数据路径，并渲染完整花譜原文校验表格与链接。后端预览检查增加未列入精选导航的艺人引用，阻止遗漏再次发布。
