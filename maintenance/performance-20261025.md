# 图片与阅读体验维护记录

本轮沿用 DESIGN.md 中的 Wiki 阅读身份，修复既有实现。没有改公开内容、用户记录或导航路径。

## 图片契约

本地图片继续由 `scripts/generate-thumbnails.mjs` 在构建时生成 WebP 候选。正文 Markdown 在消毒完成后接入响应式属性；已有 picture 艺术指导保持原样。ResponsiveImage、词条悬停预览、首页背景及图库人物图均使用适合显示槽宽的派生图。原始 URL 和原始尺寸供查看器使用，不把缩略图误当作原图下载。

公开图库卡片、组预览和编辑器公共图片库使用三档缩略图路由；原图和下载 URL 保持既有值。未知外部来源、动画原件及不可生成派生图的内容保留可用回退。服务端按图宽生成候选，浏览器按 sizes 和 DPR 选择；接口故障时只回退一次并清除失效 srcset。

## 阅读和状态

右侧资料卡随文档自然滚动；目录保留定位能力。移除正文尾部、页脚重复的发电裸链接，保留现有主入口和统一控件字级。搜索框使用对称内边距；搜索是完整视口外壳，必须带 `data-modal-layout="fullscreen"`，避免普通原生 dialog 的限宽造成第二层滚动。

局部等待统一用 loadingStatus；可访问名称和错误、重试状态保留，减少动态效果时停止旋转。布局型加载继续使用已有骨架。账号确认刷新不再每次读取收藏；首次登录、账号变化、未同步改动和重试立即读取，未变化的账号最多每五分钟主动对账一次，仍保留跨设备更新能力。

首屏HTML同样使用LoadingStatus，覆盖事件/活动、贡献者、文章关联/列表/阅读、探索、创作者、系列阅读及编辑器入口；专属支持资料页独立引入同一CSS。动态重试和图片检查复用同一方法。图库加载更多移除旧伪元素，避免出现两个spinner。真实上传字节进度、倒计时、地理选择的上下文提示和已有骨架仍保留各自语义。

## 清理依据

移除没有任何运行代码、脚本、测试、文档或原型引用的八个旧组件：ActivityPromotion、LogSection、WikiInfoBox、ContributionHubRedirect、ProjectsSection、MissingDataNotice、AlbumInfoBox、AlbumCatalogFilter。未删除已有公开路由、编辑器原型、迁移、素材或兼容入口。

## 验收边界

复核补齐新发布图库的无扩展名 revision 路径，以及公开 community-activities/assets 海报。活动卡片和系列卡片复用同一尺寸选择器；转换失败先回退原图，只有原图也失败才收起卡片图片。外部来源与私有暂存图片保持原访问路径，不传给公开转换接口。

本机桌面和手机验证覆盖搜索、资料卡、缩略图、原图查看器及账号加载。图库接口使用隔离内存数据，远程图像转换使用 Sharp 适配器；这不等于云端转换或生产身份验证。检查、固定提交、截图和剩余发布门槛记录在任务交接中。上线需先发布兼容后端，再发布前端，按现行发布规则批准固定清单。
