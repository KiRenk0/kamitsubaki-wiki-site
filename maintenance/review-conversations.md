# 投稿审查闭环

任务 `20261019-admin-experience-a1`，仍在实现及集成验收中。

`/[locale]/contribute/review/` 是五语言的鉴权页面壳，查询参数 `id` 指定本人审查记录；旧投稿链接通过 `kind` 与 `resource` 解析。静态页面不含投稿正文和讨论，不进入索引。所有数据由 `/api/reviews/*` 使用普通 Wiki 会话按实时业务归属授权，私有请求使用 no-store；账号切换清除当前内容。

文章被请求修改后，在审查页提交新修订；旧修订保持只读。图片、设定组、活动、词条和年表链接回原领域编辑器，继续使用原版本、权限和提交链路。词条和年表仍通过真实 GitHub PR 评审和合并，站内评论不自动转发到 GitHub。讨论回复在创作者中心提示，打开对应审查记录后标为已读。

新增页面和编辑器链接通过本地合成数据验证，不代表 GitHub、供应商或生产发布证据。完成候选的准确提交、状态转换和剩余验收记录在任务交接包。
