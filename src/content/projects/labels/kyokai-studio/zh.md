## 简介

「KYOKAI STUDIO」是 THINKR 旗下的音乐工作室，在 2026年9月5日的工作室重组公告中，以从「[KAMITSUBAKI STUDIO](/zh/projects/labels/kamitsubaki-studio)」分拆的形式正式设立。工作室与「持续探求自身边界的艺术家」协作，追求**坚实而自由的音乐**（日语原文：堅実で自由な音楽）。

按照 THINKR 公布的新架构，KAMITSUBAKI STUDIO 今后将专注于虚拟领域，而原神椿体系中以网络为活动据点的真人艺人与创作者阵容，则主要由 KYOKAI STUDIO 承接。在 THINKR 的「MUSIC & EXPERIENCE」板块下，KYOKAI STUDIO 与 KAMITSUBAKI STUDIO、[ALLT STUDIO](/zh/projects/labels/allt-studio) 并列。

官方网站 kyokaistudio.jp 于重组公告前（2026年8月下旬）先行上线，公开了旗下艺人 / 创作者名单。

## 发展历程

- 2026年8月下旬：KYOKAI STUDIO 官方网站（kyokaistudio.jp）上线，公开旗下艺人 / 创作者名单与作品信息。
- 2026年9月5日：THINKR 发布工作室重组公告，正式宣布 KYOKAI STUDIO 以从 KAMITSUBAKI STUDIO 分拆的形式成立；同日官网发布「KYOKAI STUDIO AUDITION」，招募次世代艺人。
- 2026年9月：原 KAMITSUBAKI STUDIO 体系（ANARCHIC RECORD、SINSEKAI RECORD、CREATOR FARM 等）的多名艺人与创作者确认移籍 KYOKAI STUDIO。
