## 概述

Empty old City 是由作曲家兼制作人 Neuron（ニューロン）与主唱 kahoca（カホカ）组成的双人音乐组合。自 2021 年以首支单曲「Urban Cruise」出道以来，凭借独特的叙事性创作手法、空灵的声线表达以及层次丰富的电子跨界制作风格，在网络音乐领域确立了鲜明的存在感。

组合原隶属于 ANARCHIC RECORD 生态体系（2026年9月随 THINKR 工作室重组移籍 [KYOKAI STUDIO](/zh/projects/labels/kyokai-studio)），在虚拟音乐与互联网音乐的版图中占据着独到的位置。作品注重电影化的世界观构建，将忧郁氛围、厚重的电子音色纹理与富含意象的歌词编织在一起，呈现出反复聆听之下愈发深邃的音乐体验。

## 角色与创作定位

组合的创作核心在于 Neuron 精密的制作工艺与 kahoca 富有表现力的演唱之间的互补关系。Neuron 的编曲汲取电子音乐至管弦乐等广泛音响素材，构建出在内省静谧与爆发性张力之间往复游走的声景。kahoca 的歌声则充当叙事的锚点，在脆弱与坚定之间保持平衡，引导听者进入故事的世界。

这种创作方式赢得了听众的强烈共鸣，尤其在制作精良的音乐与情感充沛的叙事相融合的单曲中表现突出。MV 进一步在视觉层面延展了这些叙事，巩固了组合作为"声音建筑师"的艺术身份。

## 企划定位与音乐世界观

**Empty old City** 是 [ANARCHIC RECORD](/zh/database/studios/anarchic-record) 旗下的都市风格音乐组合，由作曲家 **Neuron** 与主唱 **kahoca** 两人组成。组合于 **2020 年 10 月 31 日**结成，并于 **2021 年 1 月 20 日**以首支单曲《アーバンクルーズ》正式出道。

| 维度 | 内容 |
| :--- | :--- |
| **构成** | Neuron（作曲 / 作词 / 编曲） ＋ kahoca（主唱 / 英文译词） |
| **所属** | [ANARCHIC RECORD](/zh/database/studios/anarchic-record) |
| **结成 / 出道** | 2020-10-31 / 2021-01-20 |
| **音乐基底** | 鼓打贝斯、Trap、合成器浪潮等舞曲类型，并糅合管弦乐、爵士乐与民族音乐 |
| **题材取向** | 文明崩坏后的社会、自然环境与科技相融合的世界，幻想性的乌托邦与反乌托邦物语，以及置身其中的个体的孤独与自由 |
| **视觉体系** | 以插画形象活动，现阶段不进行露脸出演；历代曲绘由 LOWRISE、紺屋鴉江、ネア 等多位插画师执笔，多以清冷的淡蓝色调为基调 |

**「作品第一」方针**

组合奉行 Neuron 所主张的「作品第一」原则：

1. 不公开成员个人背景；
2. 不露脸出演；
3. 社交平台仅作最低限度的运用，将表达集中于作品本身。

> **叙事与声音的分工**：Neuron 谱写宛如故事般铺陈的乐曲、虚幻而优美的旋律与浓密的电子声响；kahoca 则以「**叙述者**」的歌声将这些故事传达给听众。这一「作曲者写世界、歌者讲世界」的分工，是 Empty old City 区别于一般双人组合的核心特征。

## 成员构成与分工

### Neuron

**Neuron**（ニューロン）是组合的作曲家与音乐制作人，**包揽乐曲的作词、作曲与编曲**，并负责 kahoca 的歌唱指导。

- **组建理念**：不受艺术家自身角色性的束缚，把脑海中的构想「不降低分辨率地」输出为音乐——他认为 kahoca 是自己所知歌手中歌声最具冲击力的一位，遂发出邀请；
- **对外供曲**：

| 对象 | 曲目 |
| :--- | :--- |
| [花譜](/zh/database/artists/solo/kaf) | 《アポカリプスより》《ホワイトブーケ》《黄金の木》 |
| [明透（ASU）](/zh/database/artists/solo/asu) | 《illumina》 |
| [Albemuth](/zh/database/artists/groups/albemuth) | 《Replica》 |

- **个人名义活动**：以个人名义参加ボカコレ等活动，发表有《地球最後のブルーチーズ (feat. 裏命)》《破綻するシャドウ ft. 星界》等作品。

### kahoca

**kahoca**（カホカ）是组合的主唱，以空灵通透的歌声承担将 Neuron 创作的物语与世界观传达给听众的「**叙述者**」角色，并**亲自负责组合作品 English Ver. 的英文翻译**（自《Chronicle A (English Ver.)》起成为惯例）。

- **跨企划参与**：以个人名义参加 KAMITSUBAKI STUDIO 与游戏创作者 [Kazuhide Oka](/zh/database/creators/kazuhide-oka) 共同发起的游戏×音乐企划 [ANMC](/zh/database/artists/groups/anmc)，演唱了游戏《ムーンレスムーン》开场曲《アウトライン・シーサイド》（与 harha 合作）。

> **分工的互补性**：Neuron 对外供曲时服务于他人的角色形象（花譜、明透、Albemuth），而在组合内部则完全以自己的世界观为出发点；kahoca 则在「组合作品」与「ANMC 等跨企划」之间双向移动——两人的外部活动共同扩展了 Empty old City 的创作半径。
