## 概要

KAMITSUBAKI STUDIO（神椿スタジオ）は、2019年10月18日に設立された、株式会社THINKR傘下のアートレーベル、クリエイティブ集団、およびアーティストマネジメント事務所です。「YouTubeファースト」を掲げ、音楽、映像、物語、イラスト、デザインなど様々な分野のクリエイターが集い、音楽から派生する「物語」の創出に取り組んでいます。

レーベルのキャッチコピーは **“Everything starts from here.”（すべてはここから始まる）** であり、**「音楽と物語で世界をほんの少し変える」** ことをミッションとしています。

2026年9月5日以降、THINKR のスタジオ再編に伴い、神椿は**バーチャル領域に特化**したスタジオへと移行しました。旧体系のリアルアーティスト・クリエイターは、新設の [KYOKAI STUDIO](/ja/projects/labels/kyokai-studio) などの姉妹スタジオへ移籍しています。

## 歩み

### 2018年 - 2019年：前夜とレーベル設立
- **2018年10月18日**：バーチャルシンガー[花譜](/ja/artists/vwp/kaf)（KAF）がYouTubeで活動を開始。
- **2018年12月6日**：[花譜](/ja/artists/vwp/kaf)の初となるオリジナル曲『糸』（作詞・作曲：[カンザキイオリ](/ja/artists/creators/kanzaki-iori)）をリリース。
- **2019年10月18日**：[花譜](/ja/artists/vwp/kaf)のデビュー1周年記念配信において、チームが正式に「KAMITSUBAKI STUDIO」として発足。同日に[理芽](/ja/artists/vwp/rim)（RIM）がデビューし、バーチャルラッパー[春猿火](/ja/artists/vwp/harusaruhi)（HARUSARUHI）、バーチャルダークシンガー[ヰ世界情緒](/ja/artists/vwp/isekaijoucho)（ISEKAIJOUCHO）の加入を発表。

### 2020年 - 2021年：魔女の結集とプロジェクト展開
- **2020年5月29日**：オリジナルIPプロジェクト「神椿市建設中。」を発表。
- **2020年8月12日**：[理芽](/ja/artists/vwp/rim)の代表曲『[食虫植物](/ja/songs/rim/originals/食虫植物-carnivorous-plant)』がTikTok等のプラットフォームでバイラルヒットし、累計1,000万回再生を突破。
- **2020年10月10日**：[花譜](/ja/artists/vwp/kaf)の2nd ONE-MAN LIVE「不可解弐」を開催。同ライブにて初の[音楽的同位体](/ja/artists/solo/musical-isotope)「[可不](/ja/artists/isotopes/kafu)（KAFU）」の開発を発表。
- **2020年10月25日**：5人目のバーチャルシンガー[幸祜](/ja/artists/vwp/koko)（KOKO）の加入を発表し、5人のバーチャルシンガーが出揃う。同日、スタジオの運営会社がTHINKRであることが公表される。
- **2021年3月13日**：花譜の2nd ONE-MAN LIVE「不可解弐Q2」において、花譜、理芽、春猿火、ヰ世界情緒、幸祜の5人によるバーチャルアーティストグループ「V.W.P（Virtual Witch Phenomenon）」の結成を発表。
- **2021年7月7日**：CeVIO AIを採用した初の音楽的同位体「可不（KAFU）」が正式発売。

### 2022年以降：エコシステムの拡大と多角化
- **2022年4月15日〜16日**：初のレーベル主催ライブ「魔女集会」およびV.W.Pの1st ONE-MAN LIVE「現象」を開催。
- **2022年8月24日**：花譜が日本武道館で3rd ONE-MAN LIVE「不可解参(狂)」を成功させ、バーチャルシンガーとして初の日本武道館単独公演を達成。
- **2023年3月31日**：専属コンポーザー・音楽プロデューサーのカンザキイオリが卒業。
- **2023年10月18日**：[雄之助](/ja/artists/creators/yunosuke)とWaMiによる音楽ユニット「[Awairo](/ja/artists/solo/awairo)」のデビューを発表。
- **2024年1月13日〜14日**：スタジオ主催フェス「KAMITSUBAKI FES '24」を開催。
- **2026年9月5日**：THINKR がスタジオ再編（スタジオ構造の刷新）を発表。KAMITSUBAKI STUDIO はバーチャル領域に特化するスタジオへ移行し、分岐のかたちで [KYOKAI STUDIO](/ja/projects/labels/kyokai-studio)（自らの境界を探し求めるアーティストとの協働）と [UNKNOWN LAB](/ja/projects/labels/unknown-lab)（総括プロデューサー・[PIEDPIPER](/ja/artists/creators/piedpiper) を中心とする R&D 部門）を新設。同日、公式サイトが全面リニューアルされ、スタジオ内レーベルは **PHENOMENON RECORD** に統合され、[深脊界（SINSEKAI RECORD）](/ja/projects/archive/sinsekai-studio)などのレーベル名は使用終了となりました。

## 中心となる概念

「[魔女](/ja/songs/kaf/originals/majo)」「神椿市」「[観測](/ja/albums/kaf/kansoku)」「バーチャルとリアルの境界」は、スタジオの作品を横断して現れるキーワードである。観測者は単なるファンの呼称ではなく、映像を見て、楽曲を聴き、ライブへ参加し、資料を記録することで作品の継続的な意味づけに関わる存在でもある。

神椿の制作は音楽から始まり、MV、イラスト、キャラクター、ライブ、ゲーム、小説、舞台、アニメーションへ広がることが多い。そのため一人のアーティストにも、歌手、音楽的同位体、メディア作品のキャラクター、ライブ形態という複数の記録層が存在し得る。本Wikiではこれらを分離し、関連項目として接続する。

## 初期メンバーとクリエイターネットワーク

五人の魔女以外にも、[CIEL](/ja/artists/solo/ciel)、[DUSTCELL](/ja/artists/solo/dustcell)、テレサ、多くの作曲家、画家、映像監督が神椿初期の活動に関わった。[カンザキイオリ](/ja/artists/creators/kanzaki-iori)は[花譜](/ja/artists/vwp/kaf)と初期[V.W.P](/ja/artists/vwp/vwp)の重要作品を長く支え、[Guiano](/ja/artists/creators/guiano)、大沼パセリ、Misumi、samayuzame、[PALOW.](/ja/artists/creators/palow)、orie、れおえん、SWAV、川サキらが楽曲、キャラクター、曲絵、MV、ライブ映像をそれぞれの時期に担当した。

彼らは単なるクレジット一覧ではなく、アーティストの声のイメージ、視覚言語、世界観の進行を形づくる制作層として記録する必要がある。

## 運営体制とビジネスモデル

神椿は自らを「**YouTube 発のクリエイティブレーベル**」と位置づけており、その運営体制は従来の芸能事務所とは構造的な違いがある：

| 観点 | 神椿のやり方 |
| :--- | :--- |
| **主戦場** | YouTube を主要な発表の場とすることで、**自らメディアの伝播力を握り**、既存のメディアチャネルに依存しない |
| **組織形態** | 「音楽を作るレーベル機能」と「アーティストをマネジメントするエージェンシー機能」を**内製で統合**し、アーティスト同士の創作が連動して生産速度を高められるようにする |
| **収益構造** | アーティストを主体とし、**ファンコミュニティから収益を得る**。これは「クライアントから広告費を得る」インフルエンサー型のビジネスモデルとは根本的に異なる |
| **販売チャネル** | **D2C（消費者直販）**モデルを採用し、既存の流通を介さずに利益率を最大化する |
| **再投資** | D2C がもたらした利益は、音楽制作、映像・MV 制作、宣伝、そしてアーティストへの還元に充てられる |
| **技術の内製** | AR／VR／MR などの技術を統合し、多様な形の XR ライブ表現を実現するため、**技術人材を拡充し社内で制作を完結**させる |

> **初期 VTuber との違い**：神椿は自らを「役割演技性が強く、架空のキャラクターを演じることを核とする初期のバーチャル YouTuber」と明確に区別している——所属アーティストの特色は、**音楽を主軸とし、ドキュメンタリー性の強い活動の仕方**にある。

> **設立の構想**：PIEDPIPER が神椿を設立し主導したのは、[カンザキイオリ](/ja/database/creators/kanzaki-iori) と [花譜](/ja/database/artists/solo/kaf) の二人の才能を見出したことがきっかけである；全体の構想は**日本で 88rising のような YouTube を基盤とするクリエイティブレーベルをつくること**であり、多くのクリエイターやアーティストとの出会いを経て、この構想はやがて形になった。

## 組織再編とレーベル体系の変遷

| 時期 | 組織上の出来事 |
| :--- | :--- |
| 2019-10-18 | 花譜の活動一周年当日に KAMITSUBAKI STUDIO を設立 |
| 2023-07 | **SINSEKAI STUDIO の統合**を発表し、新たな四レーベル体制へ再編 |
| 2024-05-08 | **「ALLT STUDIO」と「PHASE STUDIO」を新設**し、あわせて一部アーティストの移籍を公表 |
| 2024-08-01 | 母体である THINKR が約 50 億円のシリーズ A 調達を完了し、完全な独立経営を実現（詳しくは [THINKR](/ja/database/studios/thinkr)） |
| 2026-09-05 | THINKR がスタジオ再編（THINKR NEW STUDIO ARCHITECTURE）を公表：神椿は**バーチャル領域に特化**するレーベルへ転換し、スタジオ内のレーベルは [PHENOMENON RECORD](/ja/database/studios/phenomenon-record) に統一；従来の体系にあった実写のアーティストとクリエイターは、新設された [KYOKAI STUDIO](/ja/database/studios/kyokai-studio) などの兄弟スタジオへ分流 |

> **「レーベル内レーベル」の度重なる再編**：2023 年の四レーベル再編、2024 年の新スタジオ設立、そして 2026 年のバーチャル特化への転換と、神椿の組織史は**一〜二年ごとに構造調整を行う**リズムを示している。このリズムは「音楽 × 物語」という長期的な IP 戦略と噛み合っている——組織形態は企画の段階に応じて変化するものであり、固定されているわけではない。

## 関連ブランドと施設

中核レーベルのほか、神椿の体系には異なる機能を担ういくつかのブランドと施設がある：

| ブランド / 施設 | 機能 |
| :--- | :--- |
| **KAMITSUBAKI RECORD** | 神椿の**前身となる音楽レーベル** |
| **FINDME STORE** | 公式グッズの**通信販売ストア** |
| **TPNN** | **ファッションブランド** |
| **KAMITSUBAKI CREATION** | ビジュアルクリエイター、MV ディレクター、世界観作家のマネジメントギルド（詳しくは [KAMITSUBAKI CREATION](/ja/database/studios/thinkr-creative-guild)） |
| **[PNDR](/ja/database/studios/pndr)** | 2024 年に設立された自社開発のデジタル音楽配信プラットフォーム兼インディペンデントレーベル |

> **構造的な観察**：「前身レーベル → クリエイティブレーベル → グッズストア → ファッションブランド → クリエイターギルド → 配信プラットフォーム」と、神椿の関連ブランド群は**作品制作、商品販売、ファッション表現、産業基盤**という四つの層を覆っている。この「自己完結」のブランド構造は、D2C の収益モデルと互いに支え合っている——レーベルはコンテンツの供給側であると同時に、自らのチャネルでもある。
