観測者の皆さん、こんにちは。

**V2.3.0では、サイト内エディターから直接投稿できるようになりました。**

誤字の修正、情報の追加、出典の補足を、そのままエディターから送れます。これまでのビジュアル編集、ソース編集、Markdown の出力も引き続き利用できます。

## 編集して、差分を確認して、投稿

既存の **GitHub または Google アカウントで Wiki にログイン**し、エディターで既存の記事を選んでください。編集後は差分を確認し、変更内容の説明と出典を添えてレビューに送ります。

サイトが **GitHub の Pull Request（PR）**を作成します。Google でログインする方も、投稿のために別途 GitHub アカウントを作ったり、API トークンを設定したりする必要はありません。

**投稿しても、すぐには公開されません。** 管理者が引き続き GitHub でレビュー、コメント、マージを行い、その後サイトへの反映処理が完了すると公開されます。

## 下書きを保存して、続きを編集

ブラウザー内の下書きに加え、アカウントのクラウド下書きを手動で保存・読み込みできるようになりました。ほかの端末でも続きを編集できます。クラウド下書きの保存期間は90日です。大切な内容は Markdown として出力しておくこともできます。

投稿後の追記は「自分の投稿」から行い、同じ PR を更新できます。元の記事や PR のブランチに別の変更が入った場合は、競合する内容を比較してから更新します。

## レビューの内容をサイト内で確認

投稿パネルでは、自分の投稿、GitHub のレビューコメント、チェック結果、公開までの進捗を確認できます。同期には少し時間がかかることがあります。修正の依頼が届いたら、エディターに戻って続きを編集してください。

投稿を取り下げると、対応する PR が閉じられます。投稿の記録と既存のコメントは残ります。現在、サイト内ではコメントの閲覧に対応しており、返信とレビュー操作は GitHub で行います。

## 今回の対応範囲

既存のアーティスト、楽曲、アルバム、企画、ログ記事について、中国語・日本語・英語の Markdown を編集できます。記事の新規作成、画像アップロード、複数人による同時編集は今回の更新には含まれません。

下書きは本人だけが閲覧できます。**投稿した PR の本文、変更の説明、出典は公開される**ため、私的な情報は含めないでください。Wiki の閲覧にログインは不要です。
