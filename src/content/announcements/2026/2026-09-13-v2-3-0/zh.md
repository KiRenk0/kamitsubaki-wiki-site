各位观测者，大家好。

**V2.3.0，站内编辑器现在可以直接投稿了。**

发现错字、想补充资料，或给词条补上一条可靠来源时，可以在 Wiki 里完成编辑并提交审核。原有的可视化编辑、源码编辑和 Markdown 导出仍然保留。

## 从编辑到投稿，都在站内完成

使用已有的 **GitHub 或 Google 账号登录 Wiki**，在编辑器中选择「编辑旧词条」，载入原文并修改。提交前可以查看差异，填写修改说明和资料来源，再点击「提交审核」。

网站会代你创建一份 **GitHub Pull Request（PR）**，交给维护者审核。使用 Google 登录的观测者，也无需为投稿另外注册 GitHub 账号或配置令牌。

**提交不等于立即发布。** 维护者仍在 GitHub 审核、评论和合并，合并后还需完成网站部署。

## 草稿先保存，修改可以继续

除了浏览器内的草稿，现在也可以手动保存、读取账号下的云端草稿，在其他设备上继续编辑。云端草稿保留 90 天，重要内容也可以导出 Markdown 备份。

投稿后还想补充内容，可以从「我的投稿」继续修改，更新同一个 PR。如果原文或投稿分支已被更新，编辑器会提示核对冲突，再决定如何保留修改。

## 在站内查看审核讨论

「投稿与评论」可以查看自己的投稿、GitHub 审核评论、检查结果和发布进度。同步需要一点时间；收到修改意见后，可以回到编辑器继续完善。

暂时不想提交了，也可以撤回投稿，关闭对应 PR。投稿记录和已有讨论仍会保留。当前支持在站内阅读评论，回复和审核操作仍在 GitHub 完成。

## 这次支持哪些内容？

本次支持修改已有的艺人、歌曲、专辑、企划和日志词条的中文、日文、英文 Markdown。新建词条、上传图片和多人同时编辑暂不包含在这次更新中。

草稿仅自己可见；**提交后，PR 中的正文、修改说明和来源会公开**，请勿填写私人信息。阅读 Wiki 依然无需登录。
