Hello, observers.

**V2.3.0 lets you submit changes directly from the Wiki editor.**

Fix a typo, add information, or cite a useful source without leaving the editor. Visual editing, source editing, and Markdown export remain available.

## Edit, compare, and submit

Sign in to the Wiki with your existing **GitHub or Google account**. Choose an existing article in the editor, make your changes, review the diff, and add a change summary and sources before submitting.

The site creates a **GitHub Pull Request (PR)** for maintainer review. Contributors who sign in with Google do not need a separate GitHub account or an API token to submit.

**Submitting does not publish immediately.** Maintainers still review, comment, and merge on GitHub. The website must then finish deploying the merged changes.

## Save a draft and continue later

Alongside browser drafts, you can now manually save and load cloud drafts under your account, including on another device. Cloud drafts are kept for 90 days; export important work as Markdown for a backup.

Open My submissions to continue editing a submission and update the same PR. If the original article or PR branch changes, the editor asks you to compare the conflicting versions before updating.

## Follow the review on the site

The submissions panel shows your contributions, GitHub review comments, checks, and publication progress. Updates may take a little time to sync. Return to the editor when you need to address feedback.

You can withdraw a submission to close its PR; the submission record and existing discussion remain available. Comments can currently be read on the site; replies and review actions are handled on GitHub.

## What is included?

This release supports edits to existing artist, song, album, project, and log articles in Chinese, Japanese, and English Markdown. Creating articles, uploading images, and simultaneous collaborative editing are not included.

Drafts are private. **Submitted PR content, change summaries, and sources are public**, so leave out private information. Reading the Wiki still requires no login.
