各位观测者，大家好。

**V3.0.0 新增了两套可以一起整理的资料系统：神椿图片档案与时间轴。** 照片可以逐张收录和分类，事件可以在站内投稿和修订。站点更新也有了可回看的公告历史。

## 01 · 神椿图片档案

[进入图片档案](/zh/gallery/)，先在照片网格中浏览所有已公开图片，再按人物与团体、图片类型、标签或设定组筛选。人物和团体词条中的图集入口也会汇集与其关联的照片；一张照片可以同时出现在多个图集中。

设定图现在是一种图片类型，设定组用于保存成套资料。照片可以独立收录。点击照片即可看清原图、前后翻阅、阅读来源与署名资料，或下载图片。本站已有内容中的图片也已收录；部分旧图的原作者和使用依据仍待补充，页面会标明这一状态。

## 02 · 上传照片，继续为照片分类

[照片投稿](/zh/gallery/manage/)提供“直接上传照片”和“创建设定组”两个入口。可以一次上传多张照片，填写共用的作者、出处和使用依据，再为单张照片补充不同信息；上传时不必先选择人物或图片类型。

看到已经公开的照片需要整理？登录后可以提出分类建议：关联一位或多位人物、选择图片类型、添加标签，或补充到设定组。建议进入审核后，原有公开照片会继续显示，审核结果可在[创作者中心](/zh/account/creator/)查看。

## 03 · 可拖动、可投稿的时间轴

[神椿纪元时间轴](/zh/chronicle/)使用横向轨道和事件块。拖动轨道浏览、缩放查看密集事件，也可以切换到按日期排列的列表。持续事件的长度与实际持续时间成比例；只知道年份或月份的日期会标出不确定范围。

登录后可[新增事件或修订现有事件](/zh/chronicle/submit/)，填写日期精度、分类、关联词条和可核对来源，预览后保存草稿或提交审核。中文、日语、英语任一种都可以作为起稿语言；尚无译文时会标明原文语言。审核通过的修改随网站版本发布。

## 04 · 站点时间轴与公告历史

[站点时间轴](/zh/chronicle/?scope=site)把每篇站点公告对应为一个更新事件。拖动时间轴回看更新，点击事件即可进入新版[公告阅读器](/zh/announcements/)；阅读器保留历次公告，可以逐篇浏览。

## 05 · 投稿从哪里开始

- **词条文本**：在[站内编辑器](/zh/contribute/editor/)编辑，提交后创建 GitHub PR，由维护者审核，合并并完成网站部署后公开。
- **图片**：在[图片库](/zh/media/)上传和选用，图片文件由站点图床保存。图片可用于词条插图，也可补充资料后投稿到图库；上传文件不等于已在公开图库发布。
- **图库照片与设定组**：通过[照片投稿](/zh/gallery/manage/)填写来源、署名和分类信息，提交站内审核。已公开图片还可以补充分类建议。
- **文章**：继续使用[文章投稿](/zh/articles/submit/)的云端草稿和站内审核流程，与词条 PR 分开管理。

## 06 · 草稿与审核操作

[创作者中心](/zh/account/creator/)集中展示投稿进度、审核意见与可执行的操作。修订重投、撤回和删除按内容当前状态提供，详情中的操作位置也已统一。

文章草稿增加版本检查：同一篇草稿被其他页面或设备更新后，会保留本地编辑并提示云端冲突，避免静默覆盖。登录后的返回路径、账号切换时的数据隔离和接口失败提示也已修正。

[我的空间](/zh/account/)与创作者中心会区分本机草稿、云端草稿、待处理、审核中、待网站发布和已公开，让你知道下一步该做什么。新版[文档中心](/zh/docs/)分别提供站内编辑和 GitHub 投稿路线，说明准备材料、保存、提交、审核与常见问题。

## 07 · 更紧凑、更一致的界面

图库的搜索与筛选可以展开或收起，手机上使用集中筛选面板；当前条件可直接移除，切换页面与浏览器后退时保持一致。人物与团体入口默认展示前 8 项，展开控件沿用共用样式与动画。

编辑器整理了选区操作与浮层交互。管理后台采用待处理列表与详情分区，内容目录支持更紧凑的卡片布局；账号资料统一在“全站账号”查看。日志、记录编号、时间及差异内容使用 JetBrains Mono，正文继续使用适合阅读的字体。

公开图库加入缓存并校验内容版本。审核通过后，刷新或重新打开图库即可读取最新公开内容；个人草稿和审核状态不会进入这份公开缓存。

如遇到保存、投稿或审核异常，请附上页面网址、操作步骤和提示文字，方便定位。
