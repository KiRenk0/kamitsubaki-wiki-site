**V2.4.0 は、読む・探す・貢献する体験を整えるアップデートです。**

## ナビゲーションと動きを統一

貢献センター、マイスペース、LABs で共通のヘッダー、ボタン、ナビゲーションを使用します。選択マーカーと内容が滑らかに切り替わり、スクロール中はナビゲーションがコンパクトになります。キーボード操作と動きを減らす設定にも対応します。

## 作品の雰囲気を感じるリーダー

アーティスト、楽曲、アルバムの画像をぼかして背景に使用します。本文の背後にはマスクを重ね、目次と資料カードも共通リーダーで表示します。画像のないページは単色背景を維持します。

ネタバレ部分は標準でぼかし、ホバーでプレビューできます。最初のクリックでは内容だけを表示し、リンクを開くにはもう一度クリックします。

## 貢献の手順をわかりやすく

[貢献センター](/ja/contribute/)に、クイックスタート、サイト内編集、GitHub 投稿、画像とファイル、構文、書式、ライセンスのガイドをまとめました。

[エディター](/ja/contribute/editor/)のフォントをサイトに揃え、ツールバー、項目属性、記事選択を整理しました。ファイルガイドでは GitHub へのアップロード、参照パス、分類を説明し、原画像の圧縮は要求しません。

## 細かな操作も改善

[マイスペース](/ja/account/)も共通デザインに統一。ログインダイアログには GitHub と Google のアイコンを追加し、背景のスクロールと閉じた後の位置復元を修正しました。

カスタムカーソルを全ページで統一し、リーダー、エディター、ダイアログでの非表示や重なりを修正。特別協力者の紹介は文字を引き伸ばさずに展開します。オープニングはクリックまたは Esc でスキップできます。

投稿には引き続き管理者のレビューが必要です。不具合はページのリンクと操作手順を添えて[連絡窓口](/ja/#social-contact)へお知らせください。
