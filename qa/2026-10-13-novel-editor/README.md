## 本轮实施

- 左侧由词条列表改为当前文档大纲、素材定位和正文查找，词条库移至打开文档入口。
- 格式操作栏采用常用操作与有名称的菜单，窄屏自动换行；表格显示当前位置、行列、选择、对齐、合并拆分和退出操作。
- 折叠正文使用同一个富文本解析器与编辑内核；表单内可编辑注音等特殊节点，不必写 Markdown。
- 属性面板支持当前选择入口；全部属性通过结构化表单修改，关联词条可搜索选择。
- 图片可搜索复用站内素材，上传结果只写回仍打开的目标。
- 歌词支持批量导入、逐字片段删除，以及本地音频的真实播放时间采样；媒体支持识别平台与排序。
- 元数据进入原生编辑历史；源码应用也可撤销。未应用源码时，不允许继续改正文和属性。
- 表格 HTML 重新打开时仍为原生表格，保存列宽，并将 Wiki 注音/公式转换为阅读器支持的语义 HTML。修正阅读器安全策略的重复代码类规则以及 HTML 数学内容的渲染器选择。
- 嵌套编辑器不共享全局拖拽插件，弹窗打开与关闭后全局拖拽把手均为一个。
