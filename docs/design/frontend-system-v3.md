# V3 前台组件与信息架构

## 视觉基线与实施状态

公共界面采用黑白灰、细线、微圆角与少量冷蓝。内容和图片优先，普通列表依靠排版、间距和分隔线组织。首页和阅读器的主体布局、清晰悬停背景、词条主题色、目录和原有分批展开是保留基线。

当前首批代表页为文章列表、探索总览和共享编辑器。共享变量已生效；其余页面的专用样式尚需逐页迁移和验收，不代表全站重构已经完成。

## 页面归属和操作位置

百科、文章、探索、LABs Beta、参与共建为主区域。功能入口登记在 `src/lib/siteFeatures.mjs`；首页探索区、主菜单与探索目录读取注册表。探索入口通过 `section` 分组，页面不复制路径。

| 内容 | 位置和规则 |
| --- | --- |
| 返回与面包屑 | 标题上方，返回所属区域 |
| 主要操作 | 标题右侧，窄屏移到标题下方；一个操作区最多一个主按钮 |
| 搜索和筛选 | 内容顶部；搜索优先，低频条件放入可展开区域 |
| 分页和分批展开 | 列表底部；默认每批 12 项，收起保持合理滚动位置 |
| 加载、空结果和错误 | 原内容区域内，说明当前状态并提供必要的下一步 |

跨页面使用普通链接和面包屑。同页互斥内容使用标签或分段控件。不得为无关页面增加装饰性滑块；不得用“下一页”按钮承担失败重试。

## 配色、尺寸和动效

- 公共操作色使用 `--ui-accent-color` / `--ui-accent-rgb`；当前深色为 `#91afff`，浅色为 `#315fcb`。仅用于链接、焦点和少量状态标记。
- 词条颜色使用 `--wiki-accent-color`，由 `.wiki-theme-shell` 提供阅读器范围。不得将艺人主题色应用到整页公共工具栏。
- 主按钮采用前景与背景反差，次按钮细边框，辅助操作文字化；不可用大块蓝底替代绿底。
- 控件圆角 4px，内容容器最多 8px。桌面常规控件 38px，窄屏和粗指针设备至少 44px。
- 公共反馈 200ms。背景动画保留原本节奏；减少动态效果时停止非必要位移。
- 选择器首次定位、字体加载和容器尺寸变化不播放滑移动画；选中变化可以过渡，快速切换取消过期帧，不排队。悬停反馈与选中标记分离。
- 图片预留尺寸和比例，避免加载后改变控件几何。不可通过隐藏背景解决闪动。

## 可复用组件

| 组件 | 场景及接口 | 状态与限制 |
| --- | --- | --- |
| `WorkspaceLayout` / `WorkspaceShell` | 二级页面骨架；标准、宽屏、阅读三种宽度 | 页面业务不得自行覆盖顶部位置和工具栏几何 |
| `WorkspaceHeader` | 返回、标题、说明、操作及状态插槽 | 窄屏操作换行；不另设第二组主操作 |
| `WorkspaceButton` | `tone=primary/secondary/quiet`；支持链接或按钮 | 原生禁用、可见键盘焦点；禁用链接移除跳转目标 |
| `WorkspaceLinkCard` | 整行功能入口，标题、说明和可选索引 | 中性悬停，箭头提示；不得内嵌嵌套按钮 |
| `ContentTabs` | 互斥同页内容；唯一 id、可读 label、对应具名 slot | 支持方向键、Home、End，隐藏面板不可交互 |
| `SelectionGroup` | 图片＋名字或紧凑选项；由 ARIA 属性确定当前项 | 首次定位不滑动，悬停不覆盖当前选择；图片比例稳定 |
| `WorkspaceState` | 列表加载、空态、错误、结果摘要 | `state=loading/empty/error/ready`；内容和操作插槽；请求提示使用 `role=status` |

本页上方渲染真实共享组件，包括标签、按钮、禁用状态与空结果示例。示例只用于展示，不写入业务数据库。

### 表单、条件和分页

使用 `form.workspace-filters[data-workspace-filters]`、带文字说明的 label 和原生搜索/下拉控件。低频条件使用 `.workspace-filter-more`，搜索与清除通过 `.workspace-filter-actions` 保持在一起，分页容器使用 `.workspace-pagination`。共享样式位于 `src/styles/workspaceSystem.css`。

条件筛选必须保留现有字段和 URL 状态。加载时禁止重复分页；失败显示明确重试；空结果提供恢复筛选或投稿入口。不能用仅有图标且无可访问名称的控件替代字段说明。

## 编辑器

词条与文章共用工作台。默认专注正文，目录、属性、附件按需展开；分屏预览可选。顶部集中保存与提交，低频新建、文章管理和导入进入文件菜单。正文附近保留格式操作、块操作与插入反馈。

本机保存、服务器保存与提交审核分别表达。源码、预览、草稿保护与扩展语法保真属于功能基线。编辑器外观变化不得修改存储协议或审核规则。

## 文档来源和验收

文档中心按使用、贡献、维护开发分层。贡献中心和编辑器链接到同一份规则；正文只维护前端仓库来源，运行 `node scripts/sync-docs.mjs` 同步工作区镜像，不独立改写镜像。

至少检查深浅色、桌面、窄屏、键盘焦点、图片和字体加载、快速切换及展开收起。保留项逐项对照首页和阅读器。工程检查与浏览器结果分开记录；模拟保存通过不能代替真实登录、上传和审核验收。

## 创作工作台与图片查看器

`CreationWorkbench.astro` 共用上传布局；开发示例调用默认模式，生产上传页传入 `live`，由 `galleryUploader.js` 接入身份、批次和文件队列。示例不写入数据库。每套设定自带独立的多选文件入口与拖放区；文件选择、拖入和粘贴由所在设定确定归属，禁止恢复全局勾选、跨组移动和“应用到所选”工具条。公共来源由本组图片自动继承，单图来源仅作可选覆盖。所有公共资料字段展开；索引位于左侧，文件详情与大图预览位于右侧，上传和提交固定在列表末端的底部操作区。窄屏按设定纵向排列，点击区域不小于 44px。

`AppearanceControls.astro` 管理明暗和强调色，`appearance.mjs` 定义合法值及浏览器存储键。不要使用词条颜色给公共工具栏染色。

`imageViewer().open(items,index,trigger,options)` 是统一查看器入口。每项包含 `src`、`title`、可选 `notes`、`links`；回调包括 `onChange`、`onClose`。支持适应窗口、真实 100% 原始像素、滚轮和双指缩放、放大拖动、未放大滑动翻页。关闭恢复焦点与页面位置，只预取相邻图片。图片查看按钮独立于卡片导航，禁止替换原卡片链接或去掉阅读器背景。

审核工作台使用相同 `creationWorkbench.css`。运行 `scripts/v3/sync-gallery-contract.mjs` 同步后端样式镜像；不得各自修改镜像。加载、暂存成功、提交成功、审核通过、已公开应分别显示，不使用一个“成功”覆盖所有状态。

## 账号与创作者中心

`AccountSections.astro` 是我的空间和创作者中心共用的六栏目目录。桌面左侧显示，窄屏转为三列；栏目 URL 使用 `#overview`、`#library`、`#profile`、`#security`、`#appearance`，创作者中心使用独立路径。账号栏目由 `accountNavigation.js` 切换，不能给对应面板添加与 URL 片段同名的原生锚点，否则刷新时浏览器会自动滚动到页面中段。

创作者中心通过 `creatorCenter.js` 读取本人投稿聚合列表与提醒。筛选、分页和记录详情写入网址；宽屏详情并排显示，窄屏以可关闭的侧栏显示并锁住背景滚动。词条、文章、图库仍使用各自后端存储和真实审核状态，前端只投影展示，不能把“审核通过但未公开”计入已公开。

投稿指引使用 `ContributionFlow.astro`，成功提交后调用 `showContributionReceipt` 展示稳定记录编号和创作者中心直达链接。图片暂存、文章云端草稿和本机草稿不能显示为已提交审核。新增投稿类型时需要同时更新三种语言文案、详情路由和贡献指南。
