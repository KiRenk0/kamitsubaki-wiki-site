# V3 前台组件与信息架构

## 页面归属

百科、文章、探索、LABs Beta、参与共建为主区域。功能入口统一登记在 `src/lib/siteFeatures.mjs`；首页探索区、主菜单与探索目录读取该注册表。

跨页面使用链接；切换同页内容使用 `ContentTabs`；搜索与筛选使用表单。不得为无关页面添加装饰性滑块。

## 可复用组件

- `WorkspaceLayout`：二级页面外壳，提供页头、操作区与正文。
- `WorkspaceHeader`：返回入口固定在标题之前，主要操作放在统一操作区。
- `WorkspaceLinkCard`：整行可点击的功能入口，提供标题、说明和索引。
- `ContentTabs`：必须提供唯一 id、可读 label 和一一对应的具名 slot。支持方向键、Home、End；隐藏面板不可交互。
- `SelectionGroup`：只表达当前状态；首次定位无位移动画，悬停不覆盖当前选择。

所有组件继承原站主题变量。保持原有字体、背景、主题色；不得自行增加不相关的渐变和强调色。减少动态效果模式下关闭非必要运动。

## 编辑器

词条与文章共用工作台。默认专注正文，目录与属性按需展开，分屏预览可选。不得因插入普通文本块强制切换布局。提交、本机保存、服务器保存必须分别表达。

## 文档与贡献

文档中心按使用、贡献、维护开发分层。贡献中心展示任务与投稿记录，完整说明链接至文档正文。文档正文只维护一个来源，镜像应同步而非独立改写。

## 验收

检查深浅色、窄屏、键盘、字体与图片加载后的布局稳定性。认证失败、网络失败必须保留当前内容且展示重试方式。构建通过不等于真实上传与审核通过。
