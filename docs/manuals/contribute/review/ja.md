## 受付と記録

項目、記事、ギャラリーの提出が成功したら、元の画面で受付と記録番号を確認します。「審査状況を見る」からその記録を開くか、[マイスペース → クリエイターセンター](/ja/account/creator/)でタイトル、種類、状態から探してください。個別の詳細に意見と次の操作があります。ローカル下書きは別表示で、クラウド投稿には含まれません。記録が見えない場合はログイン中のアカウントも確認します。

## 状態の意味

| 状態 | 意味と次の操作 |
| --- | --- |
| ローカル下書き | このブラウザー内のみ。編集を続けるか書き出して保管。 |
| クラウド下書き | サービスに保存済み、審査には未提出。確認して提出。 |
| 画像の一時保存 | 非公開領域に保存済み。セットの審査提出がまだ必要。 |
| 審査待ち／審査中 | 管理者の承認待ち。同じ提案を重複作成しない。 |
| 差し戻し | 意見を読んで該当箇所を修正し再提出。 |
| 一部承認 | ギャラリーでは画像ごとに結果が異なる。個別結果を確認。 |
| 承認済み／マージ済み | 審査や GitHub マージが完了。項目はサイト更新待ちの場合あり。 |
| 公開 | 公開項目、記事、ギャラリーから閲覧できる。 |

## 修正と障害からの復帰

記録の詳細から「編集を続ける」または「修正して再提出」を選び、元稿と意見を確認します。差し戻されたギャラリー画像は、承認済み画像を再アップロードせずに修正できます。審査中の記事の旧公開版は残ります。通信が切れたら再投稿前に記録の有無を確認してください。ログイン期限切れでは再ログインし、ローカル内容も確かめます。版の競合では最新データを読み直し、変更を手動で統合してください。

## 投稿の種類によって完了条件が異なる

百科の提案は GitHub PR となり、管理者の審査後も**マージとサイトのデプロイ**が必要です。記事の修訂は D1 で承認されると公開 API から読めますが、審査中や差し戻し中は従来の公開版が残ります。ギャラリーではセット共通資料と各画像を別々に審査し、一枚以上の画像の承認が公開条件です。Creator Center は三種類を一覧できますが、詳細には実際の状態を示します。

## 問題を順番に調べる

1. **受付が表示されない:** すぐに再提出せず、Creator Center を更新し、アカウント・種類・題名・バッチを確認します。新しい記録があればそれを開きます。
2. **状態が変わらない:** 最終更新と審査意見を確認します。ギャラリーは画像別の結果、百科は PR とデプロイも確認します。ブラウザー内の下書きはサーバー投稿の証拠ではありません。
3. **差し戻し:** 理由に該当するフィールドや本文を見つけ、有効な原文を残して同じ記録から再提出します。
4. **版の競合:** 古い画面で連続送信せず、最新の公開版や審査結果を読み、変更を一つずつ統合します。
5. **公開ページが見えない:** 承認と同期・デプロイ、本文言語を分けて確認します。同期失敗時は受付番号を保存し、重複投稿しないでください。
