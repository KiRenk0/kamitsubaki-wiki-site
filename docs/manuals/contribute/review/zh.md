## 回执与记录

词条、文章或图库提交成功后，留在原页面阅读带编号的回执，点击“查看审核进度”进入该记录。也可从[我的空间 → 创作者中心](/zh/account/creator/)按类型、状态和标题查找。打开记录详情才能看到具体意见及下一步操作；本机草稿单独列出，不算云端投稿。换账号时请确认当前身份，避免误以为另一账号的记录丢失。

## 状态怎么读

| 显示状态 | 含义与下一步 |
| --- | --- |
| 本机草稿 | 只在当前浏览器；继续编辑或导出备份。 |
| 云端草稿 | 已保存到对应服务，尚未进入审核；检查后提交。 |
| 图片已暂存 | 文件存于私有暂存区，仍需提交设定审核。 |
| 待审核／审核中 | 维护者尚未批准；不要重复创建相同提案。 |
| 已退回 | 打开意见，修改对应内容后重新提交。 |
| 部分通过 | 图库可能只有部分图片通过；逐图查看原因。 |
| 审核通过，等待公开同步 | 审核已记录，但公开图库尚不可见；保留原记录，等待同步或由维护者重试。 |
| 部分公开 | 这套设定已有图片公开，其余图片仍待审核、退回或待同步；进入详情查看逐图结果。 |
| 已通过／已合并 | 审核或 GitHub 合并已完成，但词条仍需站点部署；以公开页面为准。 |
| 已下架 | 内容暂不在公开目录展示；查看记录或联系维护者了解原因。 |
| 已公开 | 可从公开词条、文章或图库页面读取。 |

在创作者中心，**未提交的本机草稿和云端草稿**可点“删除草稿”，确认后无法恢复；图库草稿中的私有暂存图片也会清理。已提交审核、已退回和已公开的记录不提供草稿删除。维护者可在后台先将已公开的文章、照片或设定组移入回收站，再从回收站永久删除；删除设定组时，其中的照片会保留为已下架的独立记录。

## 修改与故障恢复

在记录详情点“继续编辑”或“修改后重投”，核对原稿和审核意见。图库被退回的单张图片可单独更正，不必重传已通过图片；文章修改不覆盖仍在展示的旧公开版本。提交失败或网络中断时，先刷新创作者中心查找本次编号；如没有记录，再从保存的草稿重试。登录过期时重新登录并检查本机内容是否仍在。并发编辑出现版本冲突时重新读取最新版本、逐项合并自己的修改，不要覆盖别人的审核结果。

## 三种投稿的“完成”并不相同

词条的提案进入 GitHub PR：维护者审核后仍要**合并与站点部署**，才会改动静态页面。文章审核通过且公开阅读页可用后才算公开；既有公开版在待审和退回期间继续展示。图库按集合公共资料和逐图结果审核；一套设定至少有一张图获批才会公开。创作者中心把这些记录放在同一处查找，但详情会保留各自的真实状态，不用一个“成功”代替全部步骤。

## 遇到问题时按顺序排查

1. **提交后没有回执**：不要立刻重交。先刷新创作者中心并核对当前账号、类型、标题或批次；若已有新记录，打开它继续。
2. **状态未更新**：查看记录中的最后更新时间和审核意见；图库另看图片级结果，词条另看 PR 与部署进度。浏览器本机草稿不证明服务端收到了投稿。
3. **被退回**：阅读具体理由，定位字段或正文。只改需修正的部分并保留有效原文，使用原记录的继续编辑入口重投。
4. **版本冲突**：停止在旧页面重复提交，读取最新公开版或最新审核结果，逐项合并自己的改动。不要用旧草稿覆盖新版本。
5. **公开页尚不可见**：分别核对审核通过、同步或部署和当前语言；遇到同步失败，保留记录编号供维护者定位，不再次创建内容。
