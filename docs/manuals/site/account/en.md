## My Space

[My Space](/en/account/) contains the overview, Creator Center, favorites, profile, sign-in and security, and appearance settings. Public content and manuals are readable without signing in. A signed-in account is required to save a cloud draft, submit work, or see private review records. Open an individual Creator Center record for feedback and the next action.

## Appearance and browser storage

Light/dark mode and accent preferences are stored in the current browser, not synchronized between devices. An editor's **local draft** also lives in that browser. Clearing site data, using private browsing, or changing devices may make it unavailable. Save a cloud draft explicitly when signed in; local autosave is not a cross-device backup.

## Common questions

- **Why is my submission absent from the public page?** It still needs review. An entry also needs its GitHub change merged and the site updated. Check [Creator Center](/en/account/creator/).
- **Why is a 100% image upload not public?** Transmission is only one step; the server must stage the image, the set must be submitted, and a maintainer must approve it.
- **Why did an article disappear after a language switch?** Articles are listed only in their actual published content language.
- **What if content fails to load?** Retry once and check the connection. If it persists, report the page URL and symptoms through [Contribute](/en/contribute/) before creating a duplicate submission.

## Return from a task to its record

My Space separates overview, Creator Center, favorites, profile, security, and appearance. Creator Center puts returned work and new review notes first; its complete table can be searched by type, state, and title. Open a record to read its exact note and next action. After submitting from an editor, compare the receipt ID so you do not open an older draft with the same title.

Local drafts belong to the current browser and account context; cloud drafts belong to the respective submission service. Before changing devices or clearing site data, confirm a cloud save actually succeeded. If contributions seem missing after an account change, verify the signed-in identity before recreating them.

## Common checks

- **Saved, but no review record:** distinguish local save, cloud draft, and submission receipt; only the last enters review.
- **Article missing from list:** check approval and the current content language.
- **Gallery preview visible but public page empty:** the author can inspect private staging; the public only sees approved and synchronized images.
- **Operation keeps loading:** check connection and sign-in, then inspect the record list for an accepted server write before retrying.
- **Appearance differs on another device:** theme and light/dark preferences are browser-local; select them again under Appearance.
