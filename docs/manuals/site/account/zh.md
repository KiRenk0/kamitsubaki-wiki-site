## 我的空间

在[我的空间](/zh/account/)查看概览、创作者中心、收藏、个人资料、登录与安全和外观设置。未登录也能浏览公开内容及说明书；保存云端草稿、投稿和查看个人审核记录需要登录。打开创作者中心的具体记录后再阅读意见或继续编辑。

## 外观与本机数据

界面明暗模式与强调色保存在当前浏览器；换设备不会自动同步这些偏好。编辑器的**本机草稿**也保存在当前浏览器，清除站点数据、无痕模式或换设备都可能使其不可用。云端草稿须在登录后明确保存，不能把本机自动保存当作跨设备备份。

## 常见问题

- **提交后没出现在公开页？** 投稿还需审核；词条还要完成 GitHub 合并和站点更新。到[创作者中心](/zh/account/creator/)核对真实状态。
- **图片上传到 100% 却未公开？** 进度只说明传输；图片还需服务端暂存成功、提交设定审核并通过审核。
- **切换语言后找不到文章？** 文章只在已有且已公开的内容语言显示。
- **正文或图片没有加载？** 先重试并检查网络；若仍失败，在[贡献中心](/zh/contribute/)反馈页面地址和现象，避免重复提交。

## 从任务回到记录

我的空间把概览、创作者中心、收藏、个人资料、安全与外观分开。创作者中心的“需要处理”优先列出退回与新意见；全部投稿可按类型、状态和标题查找。进入记录详情才能看到具体的审核意见和下一步操作。若从编辑器提交后返回中心，先核对本次回执编号，避免点进同名旧稿。

本机草稿属于当前浏览器和账号上下文；云端草稿属于对应投稿服务。打开另一台设备或清除浏览器数据前，确认云端保存已经成功。切换账号后若看不到以前的投稿，先检查登录身份，不要在新账号重复创建。

## 常见状况排查

- **“保存成功”但没有审核记录**：看清是本机保存、云端草稿还是提交回执；只有后者进入审核。
- **文章列表没有稿件**：确认文章是否已公开，以及当前内容语言是否匹配。
- **图库预览可见但公开页没有**：作者可以看到私有暂存，公众只能看到审核通过并同步的图片。
- **某次操作一直转圈**：检查网络与登录状态，再到记录列表确认服务端是否已接受，不要先重复提交。
- **外观变化没有同步到别的设备**：主题和明暗偏好只保存在当前浏览器，可在外观设置重新选择。
