## ローカルの準備

フロントエンドのブランチと未コミット変更を確認し、Node.js と pnpm を用意して `pnpm install --frozen-lockfile`、`pnpm dev` を実行します。説明書はこのリポジトリの `docs/manuals/` だけで編集し、`node scripts/sync-docs.mjs` でワークスペースのミラーを更新します。秘密情報をリポジトリ、画像、ブラウザーログに記録しないでください。サーバーの運用、公開、障害対応は保守者の非公開手順に属し、ここには掲載しません。

## 変更に応じた確認

| フロントの変更 | 推奨する確認 |
| --- | --- |
| 説明書本文とリンク | `node scripts/check-docs.mjs`、`node scripts/sync-docs.mjs --check`。 |
| 分類と項目メタデータ | `pnpm validate:content`、影響する言語とディレクトリの確認。 |
| ページ・部品・閲覧画面 | `pnpm check`、`pnpm build`、デスクトップと狭い画面での操作。 |
| 投稿画面 | 端末内下書き、ログイン状態、エラー、受付、クリエイターセンターへの移動。 |

ビルドの成功は静的出力を生成できることだけを示します。模擬応答、ブラウザー表示、実アカウントの投稿は検証記録で分けてください。テスト資料によって既存の本文や審査記録を上書きしないでください。

## フロントエンド公開の境界

候補のコミット、ビルド結果、影響するページ、画面上の回帰項目、復旧版を記録します。公開前に保守者が依存サービスを確認し、百科・記事・ギャラリーの実際の経路を検証します。画面とサービスの状態が一致しない場合は公開を止め、再現可能な URL と受付番号を残してください。サーバーの調査・復旧には非公開手順を使います。この公開説明書にサーバーのリポジトリ、設定、データ移行、配備コマンドは含めません。
