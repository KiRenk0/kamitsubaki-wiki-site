## 公開する範囲

このリポジトリでは Astro フロントエンド、百科の Markdown、分類データ、共通部品、サイト内説明書を管理します。サーバー側は**非公開ソース**です。ソースコード、ディレクトリ構成、データモデル、権限の実装、配備資料は本説明書に含めず、外部開発者には提供しません。開発時はこのリポジトリの公開型・設定・利用者に見える動作を参照し、画面からサーバー内部を推測しないでください。

## フロントエンドの情報源

百科項目は `src/content/` の Markdown とメタデータから静的ページになります。`src/data/` には分類や年表など公開の構造化資料があります。`docs/manuals/` はサイト内説明書の唯一の本文ソースで、ワークスペース上位の `docs/` は生成されるミラーです。記事とギャラリーの公開内容はサイトのサービスから取得します。その公開状態を模した Markdown をこのリポジトリに作らないでください。

## 画面に示す投稿状態

| 内容 | フロントの入口 | 読者に見える条件 |
| --- | --- | --- |
| 百科項目 | 閲覧画面の編集・投稿センター | GitHub の提案が審査・マージされ、静的サイトが更新された後。 |
| 記事 | 記事一覧と共通エディター | 審査が終わり、公開閲覧ページが利用できる状態になった後。 |
| ギャラリー | セット単位の投稿画面 | セット情報と一枚以上の画像が承認され、公開ギャラリーに表示された後。 |

クリエイターセンターは三種類の記録を一覧にしますが、実際の状態を区別します。端末内保存、クラウド下書き、画像の一時保存、審査提出、承認、公開は同じ意味ではありません。転送率 100% やボタン操作だけで承認済みと表示せず、サービスから返された結果を使います。

## 連携の原則

フロントは画面向けに提供された結果だけを利用します。ログイン期限切れ、読込失敗、版の競合、権限不足では未提出の本文と資料を保ち、正しい復旧操作を示してください。公開ページは公開版だけを表示し、編集中の内容は権限のある投稿者画面に限ります。サービスの動作変更は保守者が非公開の手順で公開契約を確認します。本章には利用者とフロント開発者に必要な結果のみを記します。
