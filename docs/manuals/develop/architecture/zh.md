## 公开范围

本仓库维护 Astro 前台、百科 Markdown、分类数据、共享组件和站内说明书。服务端是**闭源项目**；其源代码、目录结构、数据模型、权限实现和部署资料不属于本说明书，也不向外部开发者提供。开发者只需使用前台仓库中的公开类型、配置和用户可见的行为，不应从前台界面推断服务端内部实现。

## 前台内容来源

百科词条由 `src/content/` 中的 Markdown 与元数据构建为静态页面。`src/data/` 保存分类与时间轴等公开结构化资料。`docs/manuals/` 是站内说明书的唯一正文来源；工作区上层的 `docs/` 由脚本镜像，不能在镜像里编辑。文章和图库由站点服务提供已公开内容，不在前台仓库内建立同名 Markdown 来假装其公开状态。

## 投稿界面应表达的状态

| 内容 | 前台入口 | 投稿后的读者可见条件 |
| --- | --- | --- |
| 百科词条 | 阅读器编辑入口、贡献中心 | GitHub 变更提案审核、合并并更新静态站后。 |
| 文章 | 文章专栏与共享编辑器 | 投稿审核完成且公开阅读页可用后。 |
| 设定图库 | 按设定分组的上传工作台 | 设定资料和至少一张图片获批并出现在公开图库后。 |

创作者中心将三类记录并列展示，但保持各自真实状态。“本机保存”“云端草稿”“图片暂存”“提交审核”“已通过”“已公开”不能混写。前台应以服务返回的结果为准，不能把文件传输到 100% 或按钮点击当成审核成功。

## 集成原则

前台只消费为该界面提供的服务结果。登录失效、加载失败、版本冲突或权限不足时，保留未提交的正文与资料，给出准确错误和恢复入口。公开页面只呈现公开版本；编辑中的内容仅在投稿人有权访问的界面展示。涉及服务行为调整时，由维护者通过私有流程确认公开契约，前台文档只记录用户能观察并需要理解的结果。
