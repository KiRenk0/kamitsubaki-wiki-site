# 全站账号第一版

本版本在独立的 `codex/account-v1` 分支开发。日志平台不在此次范围内。

## 用户行为

- 全站导航提供登录入口；`/zh/account/`、`/zh-tw/account/`、`/zh-hk/account/`、`/ja/account/`、`/en/account/` 提供个人空间。
- 沿用 AI 助手的 GitHub / Google OAuth 和稳定用户 ID。首次登录默认取得第三方昵称、头像；用户保存自定义资料后，后续 OAuth 登录不会覆盖。
- 昵称、语言、预设头像或自定义上传头像可修改。图片先在浏览器去除原始元数据并居中裁切，输出 256 × 256 JPEG；原图最大 5 MB，保存图片最大 64 KiB。服务端仅接受受限 JPEG，拒绝 SVG / HTML / 任意外链上传。
- 收藏与清单仅本人可读写。游客收藏留在原 localStorage 键，登录后须先预览再明确合并；账号 A、账号 B、游客各自独立。
- 本机未同步改动保留。无冲突修改可以合并；同一条目被另一设备修改时显示冲突，并提供本机导出及确认使用云端版本。
- 登录设备可查看和撤销；支持退出其他所有设备。
- 另一个登录方式必须在当前登录会话内重新验证才可绑定，且不能占用其他账号已有身份。不会按相同邮箱自动合并账号。
- 导出账号/收藏和 AI 数据为两个独立动作。AI 导出失败或超过大小限制时明确失败，不生成假成功文件。
- 用户可提交、取消待处理的注销申请。管理员开始处理后冻结账号、撤销会话；跨服务失败保留可重试状态。备份按既有保留周期过期。

## 数据与资源

D1 继续保存身份、登录会话、账号资料、小头像、收藏文档、注销申请和少量管理员操作记录。AI 对话、记忆及其导出仍在服务器 PostgreSQL。未增加日志采集、定时心跳写库、轮询式收藏同步或付费存储依赖。

每账号头像最多 64 KiB；收藏最多 2,000 条、100 个清单，文档最多 400 KB。会话 last_seen 写入节流为 10 分钟。每次页面加载确认登录；收藏在加载/本机变更后同步，失败保留重试。实际免费额度是否足够仍随全站访问量变化。

头像使用独立随机 URL；URL 不含用户 ID。客户端私有缓存最长 5 分钟；替换或注销后旧地址不再从数据库提供图片。

## 上线顺序

关联工作树：`account-v1-site`（主站）、`account-v1-backend`（Worker）、`account-v1-gateway`（服务器 Gateway），均为 `codex/account-v1`。

1. 备份并核对生产基线。Worker 基于 `feat/backend-unified-optimization` 的 `3b204b6`，不要部署归档实验分支。Gateway 基于 `dce92e9`；其原工作区未提交的其他修改没有混入本分支。
2. 部署 Gateway 新接口，运行其 `005_account_lifecycle.sql`（启动迁移）。第一版并发删除保护要求现有的单 Gateway 实例；多副本扩展前须增加跨进程协调。
3. 应用 D1 `0018_site_accounts.sql`，再部署 Worker。迁移保留用户 ID 和旧会话，并为原会话回填登录来源。
4. 部署主站。保留现有 OAuth、Turnstile、Cookie 域、允许来源、Gateway 签名密钥及 Cloudflare Access 配置。
5. 用真实 Google / GitHub 账号验证回跳、默认资料、绑定、两设备同步、AI 旧会话及上传头像。先用专门测试账号演练导出/注销。

代码回退可以保留新增表/字段，不执行破坏性逆迁移。启用双登录方式绑定后，不要回退到假设每人只能有一个 identity 的旧认证代码。处理注销后若恢复旧数据库备份，必须重新应用已完成的删除记录，避免恢复已注销数据。

## 本地验证

- Node SQLite 按顺序执行全部 D1 迁移，验证账户隔离、版本冲突、会话撤销、OAuth 绑定、默认资料/自定义资料、头像、导出及注销失败重试。
- Gateway 测试覆盖签名、所有权、处理中拒绝删除、导出大小上限、事务提交/回滚及删除墓碑。数据库测试使用查询桩；尚未对真实 PostgreSQL 执行本次迁移/删除演练。
- Chrome 使用虚构用户和内存测试 API，实测资料/头像保存、收藏合并、清单创建、第二设备同步、导出、注销取消、退出及账号隔离、五种语言窄屏、深浅主题。
- 本地验证不代表已经上线，也不替代生产 OAuth 回跳与 PostgreSQL 上线前演练。

本次结果（2026-09-08）：前端 326 项、Worker 198 项、Gateway 23 项测试通过；Astro 检查 0 错误 / 0 警告（14 项原有提示）；整站 9,313 页构建成功，最后两处客户端并发保护补丁另经浏览器打包与类型检查。正文收藏 → LABs 收藏 → 我的空间、管理员搜索/停用/恢复均通过 Chrome 实测。尚未推送或部署。

实现头像读取时按 [D1 官方类型转换说明](https://developers.cloudflare.com/d1/worker-api/#type-conversion) 将 BLOB 返回的数字数组还原成二进制，避免图片响应被当作文本序列化。
