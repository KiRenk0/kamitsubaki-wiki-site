# 使用本站

## 查阅百科

从首页百科区选择分类，或使用站内搜索查找人物、团体、作品与项目。音乐作品入口包含歌曲和专辑；首页只展示少量预览，完整内容进入目录查阅。

## 阅读词条

阅读器目录可以跳转到正文标题。关联档案用于继续查阅相关实体；形态选择器中当前档案保持选中，点击其他形态进入独立词条。资料来源不等同于文章与词条之间的显式关联。

## 文章与探索

文章专栏展示审核后公开的文章。探索包含纪元时间轴、设定图库、关联网络与世界观导览。时间轴支持图形与事件列表两种视图，筛选条件共用，列表分批展开。

LABs · Beta 收纳游戏与聊天等实验体验，不承担资料目录。

## 参与共建

在[贡献中心](/zh/contribute/)选择编辑词条、投稿文章或上传设定图。查看投稿进度时需要正常登录。不同类型的投稿使用各自的审核流程；提交不代表立即公开。

## 保存与隐私

本机草稿与服务器草稿不同。本机草稿不能当作跨设备备份；提交前检查编辑器的保存状态。不要把账号凭据或不应公开的个人资料写入投稿正文。
