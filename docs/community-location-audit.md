# 观测者企划：地点与申请资料核对

本次范围为公开日历筛选、申请／纠错表单、管理员录入／审核、详情和订阅。先保留在隔离分支，不上线。

## 地点选择

使用 Tom Select 2.6.2（Apache-2.0）和官方 `@countrystatecity/countries` 2.0.0（ODbL-1.0）的固定离线快照。国家、地区和城市选项从本站 API 按需读取，无外部在线服务、地理定位请求或地图依赖。国家名称使用当前浏览器的 Intl 本地化。

- 国家／地区 → 可选省／州 → 城市。省／州可用于缩小检索及区分同名城市。
- 直辖市作为城市选项；区县、场馆、街道和门牌号写入详细地址。目录中的其他聚落保留来源原名；上游未经核实的城市译名不自动显示。
- 缺项可明确选择手填城市，由管理员核对公开公告。地点未公布可明确标注待定，避免虚构城市或地址。
- 线上活动可不填写举办地。时区仍须独立确认；目录时区只提供可主动采用的建议，不会自动移动已填写的时间。
- 国家或省／州改变时重置下级选择；保留详细地址并提示核对。目录失败提供重试，草稿、输入和原公开版本保留。
- 下拉菜单使用浏览器顶层和既有 Floating UI，Esc 先关闭地点菜单，再关闭筛选面板。错误摘要聚焦到可见的搜索框。
- URL、公开筛选与 ICS 使用 `country`、`subdivisionCode`、`cityId`。旧 `city` 链接仍支持；唯一可匹配的旧城市名称可被新目录筛选找到，歧义名称不会自动归属。

后端根据同一快照确认国家、地区和城市对应关系并保存标准名称、编号、显示名和数据版本。数据保存在原有修订／公开 JSON 内，无账号表迁移。旧版本不会因目录更新而在公开阅读时自动改写。

## 收集字段与用途

| 字段 | 保存与审核 | 公开用途 |
| --- | --- | --- |
| 企划名称、简介、介绍、原文语言 | 草稿与修订；标题／简介提交必填 | 日历、详情、分享标题／简介；原文提示 |
| 主办方、主页 | 主办方提交必填；主页须 HTTPS | 详情主办方与主页链接；系列主页已补齐保存 |
| 公开来源 | 提交必填、可核对公告 | 详情来源链接、审核核实 |
| 分类、参与方式 | 固定选项 | 日历筛选与类型标记 |
| 日期类型、开始／结束、时区 | 日期语义、UTC 时刻及夏令时校验 | 月历／列表、详情、当地／访客时间、ICS |
| 国家、省／州、城市、地点精度 | 目录归属校验或明确手填／待定 | 地区筛选、详情地点、ICS 地点 |
| 场馆与详细地址 | 手填；改地区保留并提示核对 | 详情、日程列表、ICS；暂不接地图 |
| 状态、延期／取消说明 | 变更说明提交必填；正常安排隐藏说明输入 | 状态、变更说明、原日期和取消订阅项 |
| 截止点类型、名称、日期／时刻、时区 | 每个截止点独立校验 | 清楚标注截止点的日历／详情／ICS |
| 已有系列、届次 | 管理员审核归属；复制新届清空届次 | 系列链接、历届记录、详情届次 |
| 建议新系列 | 仅审核资料；不自动创建系列 | 经管理员确认后关联真实系列 |
| 参与链接名称、URL | HTTPS 校验 | 详情参与入口 |
| 申请联系方式 | 选填、仅管理员审核可见；站内通知反馈审核 | 不公开、不导出、不进入筛选或 ICS |
| 图片用途、说明、作者、来源、使用依据 | 私有暂存、引用、审核；授权说明私有 | 完整海报、正文、署名和来源；授权说明不公开 |

系列编辑仅展示适用的基本资料、正文和图片；其主办方主页现已保存并输出。无海报活动允许进入日历，精选宣传必须有已公开主海报。地图、定位坐标、站内报名／售票和付费广告不在本次范围。

## QA 与构建

后端独立维护目录生成及 SHA-256 校验；前端构建共享 Tom Select / Floating UI 运行时和 daisyUI 样式到隔离后端。接口测试覆盖伪造父级／名称、手填、待定、目录失败、旧城市兼容、隐私、公开和订阅的一致性。UI 集成使用真实 Tom Select 与 Worker，覆盖五种语言、保存／恢复、切换地区、失败重试及原公开版本保护。

地点数据来自社区维护目录，最终活动地点仍以主办方公开公告为准。不得把目录缺失或译名不确定的信息当作已经证实的活动资料。
