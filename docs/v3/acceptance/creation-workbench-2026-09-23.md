## 上传逻辑修订

根据本次用户反馈，上传表单改为“一套设定，一组照片”：

1. 每组独立填写角色和公共资料；所有字段保持展开。
2. 每组内部独立提供“添加本组照片”多选文件入口及拖放区。粘贴只作用于焦点所在组；不会由最后点击的全局选择器决定归属。
3. 新增一组时不复制其他组的图片或资料。去除上传端的图片勾选框、跨组移动、批量来源工具条及复制资料入口。
4. 本组照片自动继承本组来源，单图可以选填独立来源、标题和说明；封面及排序保留。
5. 底部“上传全部照片”完成私有暂存，再“提交全部设定审核”。每组进入自己的设定审核记录。
6. 文件大小、格式、分辨率、预览及逐文件传输进度保留。大图预览按所点照片所属设定浏览。

后台逐图审核仍可多选；上传器移除多选操作不改变审核权限与数据模型。
