# V3 原有体验、新结构与元数据联动验收

日期：2026-09-19。范围：原有体验恢复、新结构设计、编辑器元数据及接口联动。本记录不代表整个 V3、资料清洗、翻译或生产发布完成。

## 本轮修复

- 首页艺人图片恢复正方形；分类展开使用原有 `artist-collapsible` 高度、透明度及逐行动画，保留背景图切换。
- 首页保留详细分类层级；数据库增加编号分类目录、演唱者／制作人／曲风分段视角，修复筛选条件交叉误用及表单样式覆盖。
- 移除新增的页眉数据库区和重复 LABs；新功能从 LABs 进入。
- 阅读器恢复背景、桌面目录、手机目录、资料卡、贡献者卡、元数据完善度、歌词练习及记忆回廊联动。目录定位计入手机固定目录栏高度；长歌词限制为容器宽度。
- 形态切换修复同位体标签；阅读器将旧正文中的站内实体链接在渲染阶段解析为新路径并提供预览，不改原始正文。
- 编辑器按 V3 类型提供字段、嵌套可选属性、关系类型及实体 ID 提示；修复新建词条仍写旧字段、封面仍写旧位置的问题。既有实体 ID／类型受保护。
- 前后端使用同一份实体校验规则，增加可复现的同步脚本。新建实体、重名冲突、路径与 ID 不匹配均在后端校验。
- LABs 索引读取器升级为 V3 契约；搜索、资料库、游戏及 LABs 索引统一使用实体路径。
- 刷新不再依赖主脚本结束才移除整页遮罩；字体样式不阻塞首屏；品牌图标从整套约 5 MB 的开发依赖改为约 14 KB 的必要图形。歌词注音布局按批次读写。开发索引按文件状态复用，避免每次刷新重新解析全部正文。

## 数据库与功能页视觉修订

数据库、专栏、纪元时间轴、图库和 Labs 采用与主页一致的衬线标题、等宽编号、细线分隔与留白。样式限定在功能页容器，未改阅读器与首页。数据库桌面使用分类侧栏及双列档案列表，手机使用双列分类与单列档案；检索独立成行，提供清除条件及每批 24 条加载。时间轴改为连续日期线，仍保留四轨筛选、纪元、来源和跨词条链接。Labs 探索页移除重复导航。图库保留真实空态。

本轮通过 IAB 实际检查 1280 × 900 与 390 × 844：数据库搜索花譜得到 78 条匹配，清除恢复 1854 条；分批显示从 24 增至 48；时间轴纪元筛选得到 122 条，清除恢复 518 条且取消纪元选中。图库空态及手机布局正常。图库有图状态仍待正式素材接入验收。
