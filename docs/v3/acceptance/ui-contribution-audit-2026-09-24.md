# V3 前台巡查与投稿体验修整验收

日期：2026-09-24。分支：`V3.0.0`。Worker 提交 `d30ee74` 已发布为版本 `15608126-0313-4d01-8f4e-754c5f7148d3`；本记录区分本地界面、接口测试与真实服务，前端未发布。

## 本轮修整

- 词条编辑器桌面默认并排显示正文和实时预览，窄屏改用编辑／预览标签；「插入内容」和 `/` 打开靠近操作位置的可搜索弹出菜单。属性与大纲侧栏增加可中断动画，并尊重减少动态效果设置。顶部明确标出 GitHub PR 投稿；开关关闭时展示原因和指引。
- 阅读器相关文章沿用关联档案的标题、行式记录和展开模式，每次增加 12 篇，可收起；无文章时只显示紧凑的撰写入口，失败时可重试。公开文章接口在原有分页字段外增加相同筛选条件下的 `total`，供前台显示准确数量。
- 空文章、空图库先展示用途说明和投稿入口，有内容或用户主动筛选后才展示完整筛选。未登录创作者中心展示词条、文章、图库三类任务入口。文档中心目录改为紧凑的编辑式行布局。
- 图库上传额度、连接状态、并发数与暂存到期时间归入上传标题下方的轻量元信息行，数值从 `/quota` 读取；未取得接口值时不显示空数字，到期时间按浏览器语言和时区显示。窄屏保持同一阅读顺序，登录和接口失败有清楚反馈。
- Worker 审核界面共享黑白灰、细线、微圆角控件规范，压缩队列和统计区的视觉噪声；没有改变权限与审核存储。
