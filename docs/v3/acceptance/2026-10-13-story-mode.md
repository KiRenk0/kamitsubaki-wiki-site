# Story Mode 入坑路线（2026-10-13）

本轮完成十二项路线中的第 3 项：将现有资料编排为面向新人的分步导览。GitHub 交付目标为向 `LinkTh1rsty/kamitsubaki-wiki-site` 的最新主线提交 PR；本记录不作为生产部署或账户同步的验收证明。

## 用户可见功能

- 五种语言共有五条路线：第一次认识花谱（20 分钟）、V.W.P 是什么（30 分钟）、神椿市世界观（45 分钟）、从花谱到廻花（25 分钟）、从 PIEDPIPER 认识神椿（30 分钟）。每条六章，估计时长为导览建议，完整歌曲、视频与原作时长另计。
- 每章提供阅读目的、提问与可核对的档案。成员、歌曲、创作者、演出与时间轴从当前统一实体和明确关联自动选出；导览顺序与独立选材分别标识，未补造关系、制作署名或共同剧情时间线。
- 使用已有结构化媒体和正文明确的媒体嵌入／视频链接；按需加载播放器，默认不读取第三方播放器，不自动播放。原链接一直可用，换章和关闭播放器会停止嵌入播放。世界观人物摘要可以折叠展开。
- 上一章、直接选章和先看下一章都不自动标记已读。“读完本章”才保存完成状态；完成全部章节后出现下一条导览、Discovery 和 Graph 入口。
- 进度保存在本机浏览器，五种语言共用路线与章节身份。刷新可续读，显式分享章节优先于保存的位置。分享不包含已读状态；资料选材变化会重置旧路线进度。可重新开始当前路线，不影响其他路线；无法保存时仍可继续本次阅读。
- 首页／探索目录、对应人物与项目词条、既有世界观导览都有入口。无脚本时全部章节、资料与原链接可阅读；脚本加载失败时保留资料并提供重载。

## 数据范围

使用既有统一实体、Chronicle 与世界观官方介绍，不修改原始资料。演出章节仅选择已记录的演唱会类型，排除展览、商店与一般活动。正文仅提取已存在媒体目标，不向客户端复制正文或本地文件路径。署名只有名称而没有实体 ID 的创作者不被补造为人物关联。

## 验证

针对测试覆盖选材来源、身份与去重、媒体目标、代码和注释排除、真实五条路线、五语言复现、已读与跳过、断点续读、历史、分享、保存失败、跨窗口更新、重置隔离与播放器停止。完整验证及上游整合结果将在交付前补充。
