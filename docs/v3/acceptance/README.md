# V3 前台验收状态

历史跨服务验收记录已移至仓库外维护者归档；原文不能作为当前版本的上线证明。公开仓库只保留前台可复现的检查方法与用户可见结果。

前台候选至少检查内容校验、类型检查、构建、文档链接和关键页面交互；首页悬停背景、阅读器背景与目录、分类层级、分批展开及窄屏状态要继续保留。真实登录、词条投稿、文章审核、图库上传和逐图审核必须使用正常账号逐项走通，并在维护者的私有验收记录中区分本地、模拟与真实服务结果。未完成真实流程时，不宣称已经达到上线标准。
