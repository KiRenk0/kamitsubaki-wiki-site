# 文章区与投稿审核

研究专栏自 V3 起作为统一文章区，沿用 `/articles/` 路径和 `editorial-article` 数据类型；已有文章及分类路径不迁移。用户可阅读、登录投稿新文章、提交既有文章的修改；作者、来源、许可与关联实体继续由元数据记录。

文章目录提供“投稿文章”，进入编辑器并预选 articles，用户确认新建后才替换当前草稿，同时保留上一份草稿。文章阅读器提供“提交修改”。新稿与修改均经现有投稿分支和 PR 流程，由站长审核后合并发布；站内投稿接口不直接写发布分支。

前端投稿服务由 PUBLIC_EDITOR_ENABLED 控制，后端仍需 EDITOR_ENABLED 与 GitHub App 配置。尚未在本轮开启云端服务或修改生产分支保护。发布前应在实际发布分支启用 CODEOWNERS 审核要求、更新提交后撤销旧批准，并限制绕过；本仓库 CODEOWNERS 已将 src/content/articles 指定给 @LinkTh1rsty。仅提交 CODEOWNERS 文件不会自动强制审核。

审核动作当前沿用 GitHub PR，不宣称已新增站内管理员审稿台。文章用户只能管理自己的投稿；对已发布文章的编辑作为新修改提案提交。
